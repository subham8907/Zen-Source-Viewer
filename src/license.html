Changes in this version

This is a modified version of the original work. Changes made by Subham Mahesh:

  • Redesigned the user interface (viewer, popup and options page) with a calm, minimal look in light and dark mode.
  • Reduced the project to Firefox only; Chrome, Opera and online-demo builds were removed.
  • An End User License Agreement for the packaged add-on, which does not limit the rights in the source code under the MPL-2.0 and the 21st-Century-Liberation-License-1.0.
  • Extensions for Chrome, Edge, Opera and other Chromium-based browsers (CRX2 and CRX3 files) can be opened, also from the Chrome Web Store, Microsoft Edge Add-ons and Opera add-ons. Like every add-on site, these stores are off until you turn them on. The extension ID and public key are found with the Web Crypto API.
  • Added this License & Credits page, with the licenses of all included open-source components.
  • The viewer shows files as a collapsible folder tree, like a file explorer.
  • Code is shown in a CodeMirror 6 editor (editing, search and replace, code folding, autocompletion, JSON checking); edited files can be downloaded alone or as a new zip.
  • A Changes panel lists edited files with added/removed line counts, shows each file's diff (inline or side by side) and can revert a single change, a whole file or everything.
  • All third-party libraries are installed from npm and bundled at build time: zip.js 2, js-beautify, strip-json-comments (instead of JSON.minify) and @noble/hashes (instead of SparkMD5).
  • Compare two versions of an add-on: fetch each version from a URL or addons.mozilla.org, or upload a file, and see every changed file as a diff.
  • Patches like git: download edits or the differences between two versions as a .patch file, and apply .patch/.diff files to an add-on, including binary files (using jsdiff and fflate).
  • New name (Zen Source Viewer), add-on ID and icon.

Each modified source file carries a notice saying it was modified by Subham Mahesh.

Privacy

Zen Source Viewer does not collect, store or share any personal data, and has no analytics or tracking. It only connects to a website when you ask it to fetch an add-on or file, and only add-on sites you turned on; that website's own privacy policy applies.
